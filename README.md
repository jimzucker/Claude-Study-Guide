# Claude Study Guide

A study path for the [2026 Claude certifications](https://claudecertificationguide.com/blog/new-claude-certifications-2026), built from working through the courses at [Anthropic Academy](https://academy.claude.com/).

**14 core courses · ~48 hours** (plus optional deep dives). Not all of them are worth the same amount of your time — the Notes column says which.

> [!IMPORTANT]
> **You cannot sit the exam until you have been accepted to the Claude Partner Network.**
> You can complete all the coursework beforehand, but plan the acceptance timeline into your schedule.

> [!TIP]
> The Academy's own time estimates total 40–45 hours excluding labs, with labs adding 2–4 hours.
> Summing the per-course figures below gives 47.75 hours for the core path. Budget closer to 50.

---

## How to use this guide

1. Fork this repo (or copy the table) and tick the checkboxes as you go.
2. Take the courses **in the order listed** — later courses assume the earlier ones.
3. **Do the labs.** A lot of the course content repeats itself; the labs are where the understanding actually happens.

**Notes legend**

| Mark | Meaning |
|---|---|
| ▶ | Start here |
| ⚑ | Do the lab — highest value in the course |
| ↺ | Heavily repeats earlier material; you can move fast |

## Exam prep

Once the coursework is done, use Claude itself to drill. Ask it to generate CCAR-P-style questions matching the PearsonVue exam format, for example:

> Generate 20 multiple-choice questions in CCAR-P format covering Model Context Protocol server architecture, authentication, and multi-tool workflows. For each, give four options, mark the correct answer, and explain why the distractors are wrong.

Rotate the topic through the course list above and focus on anything you scored badly on.
