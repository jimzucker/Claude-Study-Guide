# Claude Study Guide

A study path for the [2026 Claude certifications](https://claudecertificationguide.com/blog/new-claude-certifications-2026), built from working through the courses at [Anthropic Academy](https://academy.claude.com/).

**14 courses · 326 lessons · 36 quizzes · 47.75 hours.**

> [!IMPORTANT]
> **You cannot sit the exam until you have been accepted to the Claude Partner Network.**
> Do the coursework first if you like, but build the acceptance wait into your schedule.

> [!TIP]
> The Academy's own estimate is 40–45 hours excluding labs, plus 2–4 hours of labs.
> The per-course figures below add up to 47.75. Budget 50.

---

## 1. How to use this guide

1. Fork this repo and tick off [section 3](#3-progress-tracker) as you go.
2. Take the courses **in the numbered order** — later ones assume the earlier ones.
3. **Do the labs.** Much of the course content repeats itself; the labs are where the understanding actually happens.

## 4. What each course covers

**1. AI Fluency: Framework & Foundations** — Collaborate with AI effectively, efficiently, ethically and safely using the 4D framework: Delegation, Description, Discernment, Diligence.

**2. Claude 101** — Claude for everyday work: your first conversation, effective prompting, projects, artifacts, skills, connected tools.

**3. Introduction to Claude Cowork** — Delegate multi-step work: set up workspaces, give context, run task loops, use plugins for research, documents and browser tasks.

**4. Claude Platform 101** — Build on the Claude Platform from the ground up, whether you've made a few API calls or only used the chat window.

**5. Claude Code 101** — Navigate your codebase, issue commands, standardize your development workflow.

**6. Claude Code in Action** — Run long, hands-off Claude Code sessions you can trust: steer, configure, automate, verify.

**7. AI Capabilities and Limitations** — What Claude excels at and where the boundaries lie; the fundamental constraints behind common AI-workflow pitfalls.

**8. Building with the Claude API** — Structure requests, manage system prompts, format responses, integrate Claude into custom applications.

**9. Introduction to Model Context Protocol** — The standard protocol for connecting Claude to external data sources and tools; MCP server and client architecture.

**10. Model Context Protocol: Advanced Topics** — Custom MCP servers, secure authentication, complex multi-tool workflows. ⚑ **Do the lab.**

**11. Claude with Amazon Bedrock** — Deploy, scale and manage Claude models securely in enterprise cloud environments via Amazon Bedrock.

**12. Claude with Google Cloud's Vertex AI** — The same, via Google Cloud's Vertex AI.

**13. Deploying Claude Enterprise with Confidence** — The five decisions that shape your rollout: governance, security, risk management, data privacy, compliance, large-scale user management.

**14. Building Effective Human Agent Teams (Beta)** — Design robust multi-agent systems, handle hand-offs between AI and human operators, architect complex autonomous workflows.

## 7. Exam prep

Once the coursework is done, use Claude itself to drill. Ask it for CCAR-P-style questions matching the PearsonVue exam format:

> Generate 20 multiple-choice questions in CCAR-P format covering Model Context Protocol server architecture, authentication, and multi-tool workflows. For each, give four options, mark the correct answer, and explain why each distractor is wrong.

Rotate the topic through the 14 courses above, and re-drill anything you scored badly on.
